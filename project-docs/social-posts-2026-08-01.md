# FareSteal — social post pack (data as of 2026-08-01)

All prices below are **real**, pulled from the production Neon DB on 2026-08-01.
**Every price is ONE-WAY, economy, SGD, ex-Singapore.** Never post these as return fares.

Data caveats baked into the copy:
- Discount % is only quoted where the route+month has ≥18 daily snapshots (21 days of tracking).
- Routes added 2026-08-01 (Jakarta, Dubai, Paris, Rome) have no median yet → **price-only posts, no % claim.**
- Bali / Bangkok / Hong Kong have long route history but their *cheapest month* (Oct) only just
  entered the rolling window → **price-only, no % claim.**
- **Perth is excluded entirely** — provider cache is stale since 2026-07-24 (D32); its number is wrong.

## The signature format (this is the differentiator)

Everyone posts "CHEAP FLIGHT $199!!". Nobody posts a **verdict against the fare's own price history**.
That is the only thing on the page a competitor can't copy. It leads every post:

```
✈️  SIN → TPE   $248 one-way   ·   depart 21 Sep

📊 VERDICT: GOOD PRICE
    12% below its own 21-day median ($282)

[one line: who this is for / why this date]
```

Keep the verdict line even when the verdict is boring. "FAIR — don't rush" posts build more trust
than another exclamation mark, and they're the reason people come back to check.

## Publishing rules (don't skip these)

1. **Always say "one-way."** Every number here is one-way economy. This is the fastest way to
   lose trust if you get it wrong.
2. **Date-stamp it.** "As tracked on 1 Aug 2026." Prices move; a screenshot of a stale claim will
   be used against you.
3. **Disclose the affiliate link** on every platform that requires it (IG, FB, TikTok all do).
   You already have `/disclosure` — link it.
4. **Never quote a % without ≥18 snapshots** for that exact route+month. The table above is the
   current allowlist.
5. **Post the boring verdicts.** The Sydney "don't buy" post is worth more than three deal posts.
   It's the proof you're measuring rather than selling.
6. **Re-pull before publishing.** Run the query again the morning you post — these are live fares.
